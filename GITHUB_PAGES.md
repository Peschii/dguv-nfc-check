# DGUV NFC Check auf GitHub Pages

Dieser Ordner ist die dauerhafte statische Web-Version.

## Ziel

Kostenlos hosten über GitHub Pages:

- öffentlich erreichbar
- HTTPS
- keine FileMaker-Lizenz
- keine PC-IP
- NFC-Tags können später auf die GitHub-Pages-URL zeigen

## Spalten im Google Sheet

Die App erkennt diese Spalten:

`Tag_ID`, `Bauteil`, `NaechstePruefung`, `Labor`, `Ort`

Datum geht als `YYYY-MM-DD` oder `DD.MM.YYYY`.
